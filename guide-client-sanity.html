01 — Qu'est-ce que le CMS ?

Le CMS (Content Management System) est votre espace d'administration. Il vous permet de modifier tout le contenu de votre site web — textes, images, projets, articles — sans toucher au code et sans intervention de votre développeur.

Chaque modification que vous publiez apparaît instantanément sur le site en ligne.

Ce que vous pouvez faire

  • 🏗️ Ajouter, modifier ou supprimer des projets (ASTERIA, futurs projets…)
  • 📝 Écrire et publier des articles de blog (Le Journal)
  • ❓ Modifier les questions fréquentes (FAQ)
  • 🏠 Gérer les pages Univers (Intérieurs, Terrasses, Design)
  • ⚙️ Mettre à jour les informations de contact, téléphone, réseaux sociaux
Bon à savoir : Vous n'avez besoin d'aucune compétence technique. Si vous savez utiliser Word ou un formulaire en ligne, vous savez utiliser le CMS.

02 — Se connecter

1
Ouvrez votre navigateur (Chrome, Safari, Edge…) et allez à l'adresse :
https://elite-promotion.sanity.studio
2
Connectez-vous avec l'adresse email qui vous a été communiquée (Google, GitHub, ou email/mot de passe selon votre compte).
3
Vous êtes dans le CMS. Le menu de gauche affiche toutes les sections que vous pouvez gérer.
Astuce : Ajoutez cette adresse en favori dans votre navigateur pour y accéder en un clic.

03 — L'interface en un coup d'œil

L'interface est organisée en 3 colonnes :

ZoneDescription
Menu gaucheLes catégories de contenu (Projets, Le Journal, FAQ…). Cliquez pour naviguer.
Liste centraleLa liste des documents dans la catégorie sélectionnée. Cliquez sur un document pour l'ouvrir.
Éditeur droitLe formulaire d'édition. C'est ici que vous modifiez le contenu.

Les boutons importants

BoutonAction
+ (en haut de la liste)Créer un nouveau document (projet, article, question…)
Publish (vert, en bas)Mettre en ligne vos modifications — le site se met à jour immédiatement
Discard changesAnnuler toutes les modifications non publiées
… (trois points)Options avancées : dupliquer, supprimer, voir l'historique
Important : Vos modifications ne sont pas visibles sur le site tant que vous n'avez pas cliqué sur Publish. Vous pouvez modifier et prévisualiser en toute sécurité avant de publier.

04 — Modifier les Paramètres du site

Cliquez sur Paramètres du site dans le menu gauche. C'est un document unique qui contient les informations générales.

Accueil / Hero

Modifiez le titre et le sous-titre qui apparaissent en grand sur la page d'accueil.

Contact & Réseaux

Mettez à jour vos coordonnées. Ces informations apparaissent dans le footer et la section Contact :

  • Téléphone(s)
  • Email
  • Adresse
  • WhatsApp (numéro sans espaces ni +)
  • Liens Instagram et Facebook

SEO

Le titre et la description qui apparaissent dans les résultats Google. L'image de partage est celle affichée quand quelqu'un partage votre site sur les réseaux sociaux.

Astuce : N'oubliez pas de cliquer Publish en bas à droite après vos modifications.

05 — Gérer les Projets

Cliquez sur Projets dans le menu gauche.

Ajouter un nouveau projet

1
Cliquez sur le bouton + en haut de la liste.
2
Remplissez les champs : Nom, Accroche, Localisation, Année, Statut (En cours / Livré / À venir).
3
Slug : cliquez sur « Generate » pour créer l'URL automatiquement à partir du nom.
4
Ajoutez l'image principale et les images de la galerie.
5
Remplissez la description et les chiffres clés.
6
Cochez Projet phare si c'est votre projet principal (un seul à la fois).
7
Cliquez Publish.

Modifier un projet existant

Cliquez sur le projet dans la liste → modifiez les champs souhaités → Publish.

Supprimer un projet

Ouvrez le projet → cliquez sur … (trois points en haut) → Delete. Cette action est irréversible.

06 — Écrire un Article (Le Journal)

Cliquez sur Le Journal dans le menu gauche.

1
Cliquez + pour créer un nouvel article.
2
Remplissez :
• Titre — le titre de l'article
• Slug — cliquez « Generate »
• Catégorie — ASTERIA, Architecture, Art de vivre, Marché…
• Extrait — un résumé court (2-3 lignes) affiché sur la page d'accueil
• Image de couverture — l'image principale de l'article
3
Rédigez le contenu dans l'éditeur riche :
• Écrivez du texte normalement
• Utilisez les boutons de formatage pour les titres (H2), le gras, l'italique
• Insérez des images dans le corps de l'article via le bouton +
• Pour une citation, sélectionnez le texte et choisissez « Quote »
4
Cochez Article à la une pour le mettre en avant sur la page d'accueil (un seul à la fois).
5
Cliquez Publish.
Astuce : Vous pouvez rédiger un brouillon et le publier plus tard. Tant que vous ne cliquez pas sur Publish, rien n'apparaît sur le site.

07 — Gérer les Univers (catégories)

Les Univers sont les pages détaillées accessibles via les boutons « Découvrir » sur la page d'accueil : Nos Intérieurs, Nos Terrasses, Nos Design.

Cliquez sur Univers (catégories) dans le menu gauche, puis sur l'univers à modifier.

Champs principaux

ChampDescription
TitreLe nom affiché en grand (ex: « Nos Intérieurs »)
Sous-titreLa phrase sous le titre (ex: « L'art de l'espace et de la lumière »)
Image heroLa grande image de fond en haut de la page
IntroductionLe texte de présentation (2 paragraphes)
Points fortsLes caractéristiques clés (titre + description chacun)
GalerieLes images avec légendes
CitationLa phrase mise en avant en bas de page
StatistiquesLes chiffres affichés (ex: 103 m², F3…)
Attention : Ne modifiez pas la Mise en page galerie (gallery/cinematic/editorial) sans en parler à votre développeur — cela change la structure visuelle de la page.

08 — Gérer la FAQ

Cliquez sur FAQ dans le menu gauche.

Ajouter une question

1
Cliquez +.
2
Écrivez la question et la réponse.
3
Définissez l'ordre d'affichage (1 = première question affichée, 2 = deuxième, etc.).
4
Cliquez Publish.
Astuce : Pour réordonner les questions, modifiez simplement le numéro dans le champ « Ordre d'affichage » de chaque question.

09 — Ajouter et gérer les images

Ajouter une image

Cliquez sur le champ image → Upload → sélectionnez un fichier depuis votre ordinateur. Vous pouvez aussi glisser-déposer une image directement sur le champ.

Recadrer une image (Hotspot)

Après avoir ajouté une image, cliquez dessus pour accéder au recadrage. Placez le point focal sur la zone la plus importante — le site adaptera automatiquement le cadrage selon l'écran (ordinateur, tablette, téléphone).

Remplacer une image

Cliquez sur l'image existante → Clear → uploadez la nouvelle image.

Recommandations

Type d'imageTaille recommandée
Image principale / Hero1920 × 1080 px minimum
Galerie1200 × 800 px minimum
Couverture d'article1600 × 900 px minimum
FormatJPG ou WebP (évitez les PNG pour les photos)

10 — Publier vos modifications

Le système distingue deux états :

ÉtatCe que ça veut dire
Brouillon (Draft)Vos modifications sont enregistrées dans le CMS mais ne sont pas visibles sur le site. Vous pouvez continuer à travailler dessus.
Publié (Published)Le contenu est en ligne. Les visiteurs du site voient cette version.

Comment publier

1
Faites vos modifications dans le formulaire.
2
Vérifiez que tout est correct.
3
Cliquez sur le bouton vert Publish en bas de l'éditeur.
Pas de panique : Vous pouvez toujours revenir en arrière. Le CMS conserve un historique complet de toutes les versions. Cliquez sur l'icône horloge (en haut à droite) pour voir et restaurer une version précédente.

11 — Bonnes pratiques

Avant de publier

  • Relisez vos textes pour les fautes d'orthographe
  • Vérifiez que les images sont nettes et bien cadrées
  • Assurez-vous que le slug (URL) est généré

Images

  • Utilisez des photos de haute qualité (minimum 1200px de large)
  • Privilégiez le format JPG pour les photos
  • Évitez les images trop lourdes (max 2-3 Mo par image)
  • Utilisez le hotspot pour indiquer le point d'intérêt de chaque photo

Textes

  • Gardez un ton cohérent : professionnel, élégant, sobre
  • Les descriptions courtes sont plus efficaces que les textes longs
  • Les chiffres et statistiques attirent l'attention des visiteurs

Besoin d'aide ?

Pour toute question sur l'utilisation du CMS, contactez votre développeur. Pour les modifications structurelles du site (nouvelles pages, nouvelles fonctionnalités), une intervention technique est nécessaire.
